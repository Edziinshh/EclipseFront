# Диагностика ECLIPSE FRONT

Проект использует стандартный Unreal Output Log и отдельные категории ECLIPSE FRONT. Внешний сервис логирования для прототипа не нужен: текстовые логи остаются в `Saved/Logs`, а категории позволяют включать подробности только для исследуемой системы.

## Категории

| Категория | Что содержит |
|---|---|
| `LogEFCore` | progression и общие игровые события |
| `LogEFNetwork` | подключение, назначение стороны и принятые player orders |
| `LogEFMovement` | NavMesh, построение маршрута и причины отклонения movement order |
| `LogEFCombat` | атаки, урон, смерть и снаряды |
| `LogEFAI` | волны, выбор целей, aggro и lane behavior |
| `LogEFSiege` | защита и разрушение строений, бараки и Nexus |

Каждое проектное сообщение начинается с сетевого контекста: `Standalone`, `ListenServer`, `DedicatedServer` или `Client`. Для команд и боя сообщения также содержат actor/controller, цель и машинно-читаемую причину отказа там, где она известна.

## Обычный режим

По умолчанию видны важные переходы состояния, принятые команды, смерти, progression, предупреждения и ошибки. Частые события — каждый удар, полёт снаряда, waypoint и обычный поиск цели — имеют уровень `Verbose` и не засоряют Output Log.

В Output Log удобно фильтровать по имени категории, например `LogEFMovement` или `LogEFSiege`.

## Подробный режим

Команды вводятся в консоль Unreal или в строку `Cmd` редактора:

```text
Log LogEFCombat Verbose
Log LogEFAI Verbose
Log LogEFMovement Verbose
```

Вернуть категорию к обычному уровню:

```text
Log LogEFCombat Default
Log LogEFAI Default
Log LogEFMovement Default
```

Для запуска с подробными категориями можно передать Unreal параметр:

```text
-LogCmds="LogEFCombat Verbose,LogEFAI Verbose,LogEFMovement Verbose"
```

Не оставлять все категории в `Verbose` во время долгого матча: это увеличивает размер файлов и усложняет поиск важных переходов.

## Сетевой тест

Для проверки gameplay использовать отдельный dedicated server и два client-процесса. Сначала читать серверный лог: сервер является источником истины для movement, damage, aggro, ресурсов и осады. Клиентские логи нужны для подключения, локального input и presentation.

Минимальный порядок разбора проблемы:

1. Найти первое `Error` или `Warning` в свежем серверном логе.
2. Отфильтровать нужную категорию.
3. При необходимости временно включить её `Verbose` и воспроизвести проблему один раз.
4. Сопоставить сетевой контекст, actor/hero, target и `reason`.

## Visual Logger

Когда текстового порядка событий недостаточно для NavMesh или aggro, использовать встроенный Visual Logger Unreal. ECLIPSE FRONT записывает в него:

- принятые и отклонённые точки движения;
- маршрут крипов к следующему waypoint;
- переходы состояний basic attack;
- цель, направление и радиус атаки;
- обычный engage и приоритетный re-aggro;
- forced hero aggro и acquisition radius башни.

В редакторе открыть Visual Logger командой:

```text
VisLog
```

Запустить запись можно кнопкой Record в его окне или командой `VisLog record`, остановить — `VisLog stop`. После воспроизведения проблемы выбрать нужного героя, крипа или башню на временной шкале и оставить включёнными только `LogEFMovement`, `LogEFCombat` и `LogEFAI`.

Visual Logger выполняет эти записи только во время активной записи. В обычном матче дополнительные пространственные события не собираются.
