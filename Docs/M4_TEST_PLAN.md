# M4 — сетевой тест приказов

Конфигурация: `L_TestMatch`, PIE `Number of Players = 2`, `Play As Listen Server`.

## Stop (`Space`)

- [ ] На обоих окнах отдать длинную команду движения и во время движения нажать `Space`: герой немедленно останавливается.
- [ ] Начать преследование/атаку противника и нажать `Space`: атака отменяется, герой не наносит следующий удар.
- [ ] Удерживать RMB для непрерывного пути, нажать `Space`: герой останавливается и не продолжает получать новые точки до нового нажатия RMB.
- [ ] `S` продолжает двигать камеру вниз, а удержание `T` центрирует её на controlled hero.

## Hold Position (`H`)

- [ ] Во время движения нажать `H`: герой немедленно останавливается.
- [ ] Во время атаки нажать `H`: атака и преследование отменяются.
- [ ] После `H` отдать новую RMB-команду: удержание снимается, движение или атака выполняется нормально.

## Сеть и журнал

- [ ] Каждая команда влияет только на героя игрока, который её отправил.
- [ ] В журнале сервера есть `StopOrder accepted` и `HoldPositionOrder accepted` без `Error`, `Ensure` и `Accessed None`.

## Attack-move (верхняя `4` + LMB)

- [x] Нажать верхнюю `4`, затем LMB в дальней точке: появляется голубая метка, герой начинает движение.
- [x] Поставить вражеского крипа на пути: герой подхватывает его, атакует и после смерти продолжает исходный маршрут.
- [ ] При нескольких целях в радиусе герой выбирает ближайшую допустимую цель.
- [ ] Защищённое строение не выбирается целью; после снятия защиты оно выбирается.
- [ ] Во время attack-move нажать RMB, `Space` и `H` в отдельных прогонах: прежний приказ полностью отменяется.
- [ ] Команда на listen server и client управляет только героем отправившего её игрока.
- [x] В серверном журнале есть `AttackMoveOrder accepted` и нет gameplay `Error`, `Ensure` или `Accessed None`.
