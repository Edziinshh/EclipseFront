# M1 — ручной сетевой тест Combat Loop

## Запуск

1. Открыть `EclipseFront.uproject` в Unreal Engine 5.8.
2. Убедиться, что открыта `/Game/Maps/L_TestMatch`.
3. В Play Settings выбрать `Number of Players = 2`, `Net Mode = Play As Listen Server`, отдельные окна игроков.
4. Нажать Play.

## Проверка

1. У обоих игроков видны герои разных цветов и полные полоски здоровья.
2. LMB по герою показывает жёлтое кольцо только в окне выбравшего игрока.
3. RMB по земле двигает только собственного героя.
   При удержании RMB герой непрерывно меняет маршрут вслед за курсором; отпускание кнопки сохраняет последнее назначение.
   Быстрое движение курсора не должно вызывать рывки, заметную задержку или переполнение сетевых команд.
   При команде за тестовой стеной герой обходит препятствие по NavMesh, а не проходит сквозь него.
4. RMB по вражескому герою заставляет собственного героя подойти и автоматически атаковать.
   Сближение должно идти с обычной скоростью без замедления и дрожания.
5. На каждом контакте полоска здоровья цели уменьшается примерно на 60 HP при нулевой броне.
   Атакующий кратко подаётся вперёд, а над целью появляется `-60`; подпись HP обновляется на обоих клиентах.
   Поворот героя не вращает подписи и health bar: они остаются ориентированы относительно камеры каждого окна.
   Текст читается слева направо и не отображается зеркально.
6. RMB по земле во время атаки отменяет текущую attack-order.
   Повторные RMB по той же цели не должны задерживать следующий удар.
7. Нельзя атаковать себя или героя своей стороны.
8. После достижения нуля Health павший герой перестаёт двигаться, исчезает и примерно через 5 секунд появляется на своей стартовой позиции с полным здоровьем.
9. Второй клиент видит те же Health, смерть и нового героя.

## Критерий прохождения

Все девять пунктов проходят на listen server и клиенте без crash, ensure и красных ошибок в Output Log. До этого M1 остаётся в работе.
