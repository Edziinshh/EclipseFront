# M4 — Playable One-Lane Match

Цель milestone: превратить техническую осаду в управляемый и стабильно повторяемый однолинейный матч.

## M4.1 — Базовые приказы

- [x] `Space`: серверный Stop отменяет движение, преследование и basic attack.
- [x] `H`: серверный Hold Position отменяет активный приказ и фиксирует режим удержания позиции.
- [x] Новая команда движения или атаки снимает Hold Position.
- [x] Нажатие `Space/H` прекращает локальную отправку маршрута от удерживаемой RMB.
- [x] Центрирование камеры перенесено с `Space` на `T`; `S` свободно используется для движения камеры вниз.
- [x] Сервер проверяет владельца героя, смерть и финальную фазу матча.
- [x] Собрать Editor target UE 5.8.
- [ ] Пройти сетевой тест listen server + client.

## M4.2 — Attack-move

- [x] Верхняя `4` включает локальный режим выбора точки; следующий LMB отправляет attack-move.
- [x] Сервер валидирует destination и является владельцем состояния приказа.
- [x] Герой периодически выбирает ближайшего вражеского героя, крипа или уязвимое строение в радиусе 650 units.
- [x] После завершения боя герой продолжает путь к исходной точке.
- [x] RMB, прямая атака, `Space` и `H` отменяют attack-move.
- [x] Точка приказа кратко отмечается голубым кругом локально.
- [x] Собрать Editor target UE 5.8.
- [ ] Пройти сетевой тест listen server + client.
