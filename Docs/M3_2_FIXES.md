# M3.2 — исправления 2026-09-05

Снаряд больше не использует полный DeltaSeconds кадра своего создания: сервер хранит время запуска и последнего шага и интегрирует только прошедшее после запуска игровое время. В кадре запуска движение и попадание запрещены. При низком FPS движение остаётся дискретным; это исправление не гарантирует плавную картинку при 3 FPS.

В лог попадания добавлены имя снаряда и длительность полёта. Смерть/удаление источника или цели отменяет снаряд с записью причины. Существующее правило прототипа сохранено: выстрел разрушенной башни не наносит урон.

Alt проверяется каждый локальный кадр; показ и скрытие логируются. Круги героев и крипов находятся у основания капсулы, линии существуют один кадр. Это пока debug presentation, не финальный интерфейс Shipping-сборки. Круг показывает AttackRange без технического допуска CombatComponent в 20 units.

Принудительное агро башни освобождается в кадре истечения таймера, без лишнего цикла удержания. Истечение и потеря цели логируются. Отсутствие hero-aggro в предыдущем прогоне не доказывает неисправность: сценарий требует отдельной проверки.

## Проверка после сборки

Editor target UE 5.8 собран успешно 2026-09-05. Проверки ниже ещё требуют игрового прогона; M3.2 не отмечен завершённым.

- Listen server + два клиента: проверить выстрелы, попадания и отмену после смерти цели.
- При ограничении FPS до 3 убедиться, что flight в логах положителен, попадания в кадре запуска отсутствуют; затем вернуть прежний лимит FPS.
- Проверить удержание/отпускание обоих Alt и смену фокуса: круги исчезают, не оставляя следа.
- Ударить вражеского героя в радиусе его башни при наличии крипов: проверить hero-aggro, затем выйти из радиуса или дождаться 2,5 секунды без новых ударов.

## Следующий предлагаемый этап

После проверки M3.2: Core на каждую сторону, неуязвимость Core до разрушения своей башни, серверная победа и экран результата на всех клиентах. Сохранить одну башню на сторону для первого законченного матча; дополнительные башни добавить после проверки этого цикла. Затем первая активная способность героя через GAS.
